DOWN UNDER — AUSTRALIA ARRIVAL GUIDE

HOW TO OPEN
1. Keep index.html, style.css and script.js in the same folder.
2. Double-click index.html to open the site in Chrome.
3. You need an internet connection for the photos, fonts and external links.

WHAT IS INCLUDED
- Responsive layout for phones, tablets, laptops and desktop computers.
- All six main guide sections are available as feature cards on the homepage.
- Home-page search with suggestions for important words and guide sections.
- A small, collapsed tip widget that can be expanded or hidden so it does not cover the page.
- Click a city name or “See places and photos” to open tourist attractions, pictures and links.
- Plus/minus symbols update when tourist panels and information accordions open or close.
- Checklists save in this browser on this device.

HOW TO EDIT
- index.html: words, sections and links.
- style.css: colours, layout and design.
- script.js: tips, search suggestions, checklists and tourist-place details.

NOTE
This is a static website. It does not have user accounts or cloud syncing. Rules can change, so check official Australian and state websites for the latest information.
